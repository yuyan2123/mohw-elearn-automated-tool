# e 學園學習助手

這是 Manifest V3 擴充功能，適用於衛生福利 e 學園的教材教室。它使用平臺原有的教材選單、離開課程與上課按鈕。

## 載入

1. 在 Chrome 開啟 `chrome://extensions`。
2. 開啟「開發人員模式」，按「載入未封裝項目」。
3. 選取本資料夾，然後從課程資訊頁按「上課去」。如果教室原本就開著，先用「離開課程」正常結算，再重新進入。

更新已載入的版本時，先按「結算並查看時數」，再到 `chrome://extensions` 點擴充功能的「重新載入」。自 1.0.1 起，擴充功能會讀取 LCMS 檔案檢視頁，確認內嵌檔案是否載入。

## 使用

- 從課程資訊頁正常進入教室時，灰色遮罩與箭頭會標出學習助手。按「知道了」、Esc 或直接操作面板即可關閉，結算後自動接續教材時不會再次顯示。
- 教室左側的「學習助手」顯示上次從課程資訊頁讀到的已入帳時數、課程門檻、剩餘時間與本段前景學習估算。
- 看完一篇可按「結算並看下一篇」。擴充功能會離開課程、讀取更新後的時數，再透過原有入口開下一篇。達標時停在課程資訊頁。
- 「影片播完自動結算並接續」預設勾選，在前景分頁看完影片後會自動執行上述流程。取消勾選後，可按「結算並看下一篇」手動接續，取消狀態會帶到下一篇。Chrome 若要求手動播放，請點影片內的播放鍵。文字和 PDF 由你讀完後按「結算並看下一篇」。
- 「結算並查看時數」會回到課程資訊頁。已入帳時數與其他完課條件以該頁為準。
- LCMS 內嵌 PDF 成功載入後，面板會顯示「檔案閱讀中」，並在課程位於前景時估算本段時間。

接續功能需要平臺成功顯示入帳數和課程門檻，並在同一個前景分頁完成導覽。跨課程或無法辨認教材時，請用網站原本的導航。擴充功能在目前瀏覽器工作階段依分頁保存時數快照與接續狀態。
